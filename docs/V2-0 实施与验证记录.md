## 4. 实施适配与边界

1. 计划要求冻结契约，本阶段采用隔离的可执行 Pydantic 原型，以便在集成前证明拒绝条件；没有直接修改旧模型。所有跨对象语义、工具注册表与实际调用账本仍需 P11/P13/P14。
2. Windows 多进程日志用认证的 localhost TCP JSON 通道验证单写入者，避免与 MCP stdout 共用。同步 ACK 是 Spike 手段；生产排队、启动注入和异常接入另行实现。
3. TraceEvent 禁止额外字段，因此先用稳定行号引用桥接，不向旧 Trace 填新 event_id；后续桥接层需解决单事件生成和去重。
4. 财务原型暂限人民币，外币不会被错误归一为千元；这是 P24 最小范围，不表示多币种转换已实现。实际公式、字段提取/换算和勾稽没有提前接生产。
5. 公告 PDF 文本可定位候选表格，但截图工具失败；未把文本定位当作字段视觉复核，也未冻结新的真实材料。
